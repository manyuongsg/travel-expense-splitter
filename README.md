# Travel Expense Splitter

A mobile application built with React Native and Expo to help users manage and split expenses during travel. This application allows users to create groups, add expenses, and easily calculate who owes what, making group travel simpler.

## Features

*   **Group Management**: Create and manage groups for different trips or events.
*   **Expense Tracking**: Add expenses with details such as amount, description, and who paid.
*   **Expense Splitting**: Automatically split expenses among group members.
*   **Balance Overview**: View a summary of who owes whom to easily settle debts.
*   **User Authentication**: Secure user accounts to keep your data private.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

You need to have Node.js and npm installed on your machine. You also need to have the Expo Go app on your mobile device to run the application.

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/your_username/travel-expense-splitter.git
    ```
2.  Install NPM packages
    ```sh
    npm install
    ```

### Running the application

You can run the application in various modes:

```sh
# Start the Expo development server
npm start

# Run on Android
npm run android

# Run on iOS
npm run ios

# Run in the web browser
npm run web
```
